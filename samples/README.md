# Sample data

Safe inputs for trying the application. Both photos were generated by this application's own image model (Gemini)
during development, so they contain no third-party photos, logos or personal data.

| File | Use it for |
|---|---|
| `red-mug.png` | Photo input (F02, F03, F07). The handle makes it easy to check the views: with the handle on the right in the front view, it points at the camera in the left view, is hidden in the right view and is on the left in the back view. |
| `brass-desk-lamp.png` | Photo input, or photo and description together with the lamp line in `descriptions.txt`. |
| `descriptions.txt` | Descriptions for description-only generation (F06). |
| `not-an-image.txt` | An unsupported file, to see the input check reject it (F02). |

The reverse image search (F04) usually finds no matching web photos for these images, because they are AI-generated
and not real products, so the agent falls back to generating the views from the input. To see web photos being
collected, use your own photo of a real, branded product.

## Try it (CLI)

From `backend/ai-mesh-generator`, after setting up `.env` as described in the main [README](../README.md):

```text
java -jar target\ai-mesh-generator-0.0.1-SNAPSHOT.jar --spring.profiles.active=cli
> projects new Mug
> generate --image ..\..\samples\red-mug.png
> images list
> build
```

In the GUI, create a project and drag a file from this folder onto the photo list.
